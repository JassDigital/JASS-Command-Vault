# JASS Command Vault V2

Serious local-first PySide6 command and workflow workstation.

**Seed library: 363 entries.**

Practical coverage: PowerShell, Git, GitHub CLI, Python, Debian/MX Linux, Docker,
Node/Next.js, Vercel, Cloudflare, Ollama/local AI, SQLite/PostgreSQL, FFmpeg/PDF,
86Box/DOS/Windows 3.x, networking/SSH, and file/backup diagnostics.

Features: search, category filtering, favorites, copy/run, placeholders, safety
labels, guided recipes, SQLite storage, and no cloud dependency.

## Run
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m app.main
```
Or double-click `run_windows.bat`.
